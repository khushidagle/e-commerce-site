# Click 'N Shop 🛍️

**Click 'N Shop** is a fully responsive, modern e-commerce front-end application built to offer a seamless shopping experience for men's and women's apparel, accessories, and lifestyle products. 

Designed with a clean, user-friendly, pink-themed aesthetic, the website features distinct category breakdowns, interactive product showcases, a dedicated help desk, and stylized authentication workflows.

## ✨ Key Features

* **Gender-Specific Categories:** Individual portals dedicated to curated collections across contemporary Men's Wear and Women's Wear.
* **Granular Collections Grid:** Instantly browse specialized sub-categories including Winter Collections, Designer Sarees, Footwear, Handbags, and Indian Attire.
* **Product Catalog UI:** Card modules embedded with item labels, realistic pricing, delivery estimations, "Add to Cart" toggles, and instant checkout links.
* **Interactive Accordion FAQ:** Built-in frequently asked questions page resolving basic buyer tracking, support, and exchange queries.
* **Responsive Layout:** Grid and flexbox-driven architecture that naturally scales across mobile, tablet, and desktop display resolutions.
* **Our Story Section:** Dedicated narrative brand page outlining the company's creative journey, core design focus, and localized vision.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic architecture to define layouts, structured tables, and accessible input fields.
* **CSS3:** Custom stylesheet architecture utilizing modern layout modules (Flexbox/Grid), variables for the signature pink color palette, and subtle hover animations.
* **Vanilla JavaScript:** Powers interactive page functions including the help center's FAQ accordions and interactive UI element controls.
